# BastanMonitor
This is an extension for managing all the sites we've designed with Joomla. 
It can help with updating extensions, Joomla itself, or the PHP version we’re using.
It also gives us warnings about potential hacking attempts, shows our latest backups, and even lets us track domains, hosts, server, etc. expiration dates.
In short, it provides an overall management overview for all our sites. There's no limitation and it's completely free.
